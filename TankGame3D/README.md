# Tank 3D (Godot 4.3+)

التحكم على الهاتف: اسحب في النصف الأيسر للحركة (أمام/خلف/دوران)، واضغط في النصف الأيمن لإطلاق النار.
على الحاسوب: WASD/الأسهم + Space.

## التصدير لأندرويد
1. افتح المجلد في Godot 4.3+ (Import → project.godot).
2. Editor → Manage Export Templates → Download.
3. Project → Export → Add → Android (ثبّت Android SDK و JDK من Editor Settings).
4. Export Project → ملف APK.
